# A Simple JavaScript Shopping Cart

## Introduction
This site was developed to demonstrate a simple, responsive shopping cart using just HTML, CSS, and JavaScript. JS is used to build out the majority of the site, in order to more easily add or remove products. It also stores the cart to local storage, allowing users to come back later and continue their shopping.

## Functionality
In order to use this site, open the link (https://aaryhash.github.io/simple-js-cart/) and click the "Add to Cart" button below any product. This will add it to the cart and update the cart summary. Adding more of the same product with that button will increase the quantity. Resizing the browser window will adjust the products and cart to align with more narrow device sizes. Reload the page to demonstrate how the cart saves to local storage.

## Future Plans
If this project were to continue, some additional features could be to add discount functionality, add login and authentication functionality, and move the products to a different home page than the shopping cart page.

## Personal Use
To use this site for personal use, developers can change the products in the "productsList" array in the .js file to show their own items. They can also update the logo in the .html file, and/or update the view of the site through the .css file.
